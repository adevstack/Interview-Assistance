# AI Interview Preparation System

An AI-powered interview preparation system with role-based interviews, NLP evaluation, and feedback generation.

## Features

- User authentication (registration, login, logout)
- User role selection (software_engineer, hr, etc.)
- Multi-stage interview flows based on user role
- Question generation for different categories
- Answer collection and evaluation
- Real-time feedback generation
- Voice input toggle
- Dark theme UI

## Tech Stack

- **Backend**: Flask, SQLAlchemy, Flask-Login
- **Database**: SQLite (development), PostgreSQL (production)
- **NLP**: TextBlob, NLTK, language-tool-python
- **Frontend**: Bootstrap 5, Vanilla JavaScript

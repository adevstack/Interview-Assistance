Component Library
Buttons
Primary: Filled blue (#3b82f6), white text, 8px border radius
Secondary: Outline, blue border, blue text, 8px border radius
Danger: Red fill (#ef4444), white text, 8px border radius
Text Link: No background, blue text, underline on hover
Cards
Standard Card: Dark surface color (#2c2d30), 8px border radius, subtle shadow
Interactive Card: Same as standard but with hover state (slight lift)
Metric Card: Surface color with accent border, metric value prominent
Form Elements
Text Input: Dark input (#3a3b3e), light text, accent focus state
Dropdown: Same style as text input with dropdown icon
Radio/Checkbox: Custom styled with accent color for selected state
Status Indicators
Progress Bar: Accent color fill, dark background, rounded ends
Score Circle: Circular border with percentage fill based on value
Recording Status: Animated indicator with pulsing effect when active
Responsive Design Specifications
Desktop (1200px+)
Full 3-column layout for features
Dashboard shows all stats cards in a row
Side-by-side layout for feedback metrics and text
Tablet (768px - 1199px)
2-column layout for features
Dashboard shows 2x2 grid for stats cards
Stacked layout for feedback components with adequate spacing
Mobile (320px - 767px)
Single column layout throughout
Condensed header with hamburger menu
Simplified voice interface with larger tap targets
Vertically stacked metrics cards
Interactive Elements & States
Voice Recognition Flow
Initial state: Microphone button with "Start Speaking" text
On click: Button changes to active state, animation begins
While recording: Waveform visualization, real-time text appears
Processing state: Loading indicator, button disabled
Complete state: Full transcript visible, submit button enabled
Answer Submission Flow
Submit button disabled until answer recorded
On submit: Loading state with "Analyzing your answer..."
Analysis complete: Transition to feedback screen with score animation
Score circles animate from 0 to final value
